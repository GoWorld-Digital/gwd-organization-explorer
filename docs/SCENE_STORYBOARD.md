# Cinematic Opening Storyboard

Target duration: 16–22 seconds if played in full. It must be skippable and must never block navigation. With reduced motion, render the final state and use only simple opacity transitions.

| Time | Beat | Visual direction | Information |
|---|---|---|---|
| 0–2s | Signal | Deep navy field; one restrained signal line and point | GWD / AI-Native Organization |
| 2–5s | Nucleus | Central structure emerges through precise light paths | The organization is a designed system |
| 5–9s | Architecture | Five layers assemble and settle, one at a time | Governance → Executive → Shared Services → Business Units → Labs |
| 9–13s | Capabilities | Pull back; 18 capability clusters illuminate around the structure | 18 capability domains |
| 13–17s | Evidence | Metrics/status labels fade into the UI | 5 proposed layers, 18 divisions, 283 upstream source profiles |
| 17–22s | Invitation | Camera settles; actions become available | Explore organization / capabilities / missions |

## Narrative rules
- Motion explains the structure; it never hides essential information.
- Skip, pause, reverse/reset and 2D view are available.
- The number 283 must always say “source profiles”; never “active agents”.
- The proposed-model status is visible during or immediately after the intro.
- Only one primary visual event at a time.

## Interaction choreography
Layer selection: highlight → camera focus → detail panel.
Capability selection: highlight cluster → show related functions → open profile explorer.
Mission selection: transition from architecture to mission flow while preserving a breadcrumb.
Reset: return to overview.

## Sensory design
No autoplay audio. No flashing effects. Avoid continuous high-amplitude motion. Sound, if explored later, is opt-in and not required for comprehension.
