# Roadmap and acceptance criteria

## Phase 0 — Repository and product foundation
Confirm repository ownership; establish instructions, skills, product brief, architecture and visual direction; pin the Agency Agents source commit; create design review checklist.
**Exit:** scope, truth rules, stack and acceptance criteria documented.

## Phase 1 — High-fidelity visual prototype
Landing page with skippable cinematic opening; static 3D organization stack with five layers; selectable details; desktop/mobile artboards; working 2D fallback.
**Exit:** visual review approves hierarchy, legibility, motion intensity and mobile strategy.

## Phase 2 — Organization Explorer
Typed organization data; 2D hierarchy; synchronized 3D selection; details, status labels and provenance; camera states/reset.
**Exit:** every layer and unit is explorable without 3D-only information.

## Phase 3 — Agency Agents catalogue
Reproducible import; exact pinned commit; accurate 18 division counts; search/filter/profile detail; attribution/review status.
**Exit:** counts match snapshot and every profile has provenance.

## Phase 4 — Mission and business-model simulators
At least one illustrative mission; capability/unit participation; human approval gates; centre definitions; labelled assumptions.
**Exit:** visitor can follow the scenario and distinguish simulation from live operation.

## Phase 5 — Cinematic polish
Choreographed reveal, controlled camera, layer/capability transitions, optional subtle sound, reduced-motion path.
**Exit:** compelling quality without impairing orientation, readability or performance.

## Phase 6 — Production readiness
Accessibility/security review; responsive browser QA; performance budget; SEO/social metadata; license/attribution review; error/loading/fallback states.
**Exit:** production checklist signed off by human reviewer.

## Phase 7 — Controlled public launch
Vercel project connected; preview reviewed; custom domain configured only after owner approval; production deployment human-approved; public claims reviewed.
**Exit:** public launch with rollback path.

## Critical acceptance criteria
1. Visitor understands five layers within 30 seconds.
2. Selecting a layer reveals correct details and related units.
3. Reporting, service and capability edges are visually distinct.
4. The 18 capability divisions have accurate counts from pinned source commit.
5. All 283 profiles, if imported, are source catalogue profiles—not active GWD agents.
6. Mission scenarios say illustrative, not live operations.
7. No invented financial metrics.
8. Experience works with reduced motion and without WebGL.
9. Core navigation is keyboard-operable.
10. No operational database or secret is needed for public release 1.
