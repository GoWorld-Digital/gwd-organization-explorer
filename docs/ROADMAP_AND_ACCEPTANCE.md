# Roadmap and Acceptance

## G0 — Blueprint
Product scope, proposed org model, source provenance, art direction, scene specification, storyboard, mockups, AI instructions and prompts. This phase creates no application code or deployment.

## G1 — Application foundation
Initialize stable Next.js/React/TypeScript/Tailwind; add design tokens, route shell, schemas, static data, accessible 2D org hierarchy, tests and CI.
Acceptance: typecheck/lint/unit tests/build pass; all five layers render with proposed labels; capability divisions total 283.

## G2 — High-fidelity vertical slice
Cinematic opening; 3D five-layer structure; 18 capability anchors; camera states; selection synchronizes 3D, 2D and detail panel; reduced motion and WebGL fallback.
Acceptance: 1440×900 and mobile 390px usable; keyboard/touch work; no hover-only actions; no 283-mesh scene.

## G3 — Capability explorer
18 division overview, source count/provenance, search/filter, individual profile details only when approved data is included.
Acceptance: no claim of active agent deployment; attribution/source link present.

## G4 — Mission and business simulators
Curated mission templates; deterministic capability mapping; cost/profit/investment-centre model; transparent formulas.
Acceptance: formulas tested; values clearly illustrative; human approval gates represented for legal, client, security and financial decisions.

## G5 — Ventures & Innovation
Proposed Labs, experimental pipeline and venture portfolio with hypothesis/research/prototype/validation/proposed/launched states. No false claims of launched entities.

## G6 — Preview and public release
Vercel preview, browser QA, visual review, accessibility/performance checks. Configure domain and release only after human owner approval.

## Definition of Done
A clear user outcome; status/provenance shown; readable and accessible 2D fallback; responsive design; tests pass; screenshots attached; no factual overclaim; preview reviewed; documentation updated.
