# Experience Architecture

## Navigation
Primary navigation: Explore, Organization, Capabilities, Missions, Ventures, About the Model. The opening view offers three obvious actions: Explore the organization, Explore capabilities, Run a sample mission.

## Organization Overview
A full-screen/near-full-screen architectural stage with five layers, 18 capability clusters, GWD identity, a compact navigation, a contextual panel, a provenance/status strip and a visible 2D View / Reset action.

Selecting a layer must:
1. Highlight the selected geometry.
2. Move the camera to a named, restrained focus.
3. Open a detail panel with purpose, sub-functions, relationships and status.
4. Update the synchronized 2D structure.
5. Offer a “show connections” mode.

All actions work by click, keyboard and touch; never rely on hover alone.

## Organization Explorer
The 3D canvas provides spatial orientation. The 2D hierarchy provides precise reading, focus order and fallback. Details show the status, scope, parent, related units and any evidence/source.

## Agency Agents Explorer
Start from 18 division cards or constellation clusters. Show division name/count/provenance. Selecting a division opens a searchable 2D list. Profile details are only included when the content has been reviewed for licence, safety and provenance. Clearly label upstream profiles as source templates, not active GWD agents.

## Mission Simulator
A visitor selects an illustrative objective such as launching an Academy, planning a campaign, building a customer workflow or validating a venture. The interface shows:
- mission objective and assumptions;
- required capabilities;
- units/shared services involved;
- work sequence and dependencies;
- human approval gates;
- indicative resource and cost model, if enabled.

V1 uses curated templates and deterministic mapping; no AI API or actual agent execution is needed.

## Business Architecture Simulator
Distinguish cost centres, profit centres and investment centres. Show illustrative assumptions and formulas beside results. Inputs and outputs use local calculations. No real GWD financials or projections.

## Ventures & Innovation
Show proposal states: hypothesis, research, prototype, validation, venture proposal and launched (only when verified). Never present a proposed venture as an operating company.

## Interaction rules
One primary interaction per region. Avoid scroll-jacking, hidden controls and forced camera moves. Details readable at standard zoom. Reset and 2D view always available. Mobile defaults to a 2D-first experience with optional lightweight 3D.
