# GWD project standards

- Read AGENTS.md before making changes.
- This repository builds a public, read-only organization explorer. It is not Ops Core.
- Use Agency Agents as the only initial external capability catalogue. atlas-agent-packs is out of scope.
- Source profiles are not active GWD agents.
- The organization model is proposed unless approval evidence exists.
- Economic scenarios are illustrative, never actual results or forecasts.
- Use DOM semantics for core content; 3D must have a 2D/list alternative.
- No operational database, credentials, live execution or production integration in release 1.
- Use stable dependencies and docs/TECHNICAL_ARCHITECTURE.md.
- Capture browser screenshots and verify reduced-motion, keyboard and mobile before declaring visual work complete.
- No deployment, DNS change or merge without explicit human authorization.
