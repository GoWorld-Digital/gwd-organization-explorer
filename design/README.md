# Design source

These SVG boards are authored product wireframes and art-direction targets, not screenshots of a finished implementation.

- 01-cinematic-landing.svg — opening statement and spatial organization reveal.
- 02-organization-explorer.svg — main desktop explorer with layer navigation and detail panel.
- 03-mission-simulator.svg — illustrative scenario flow and participation map.

Use them as visual direction, not as pixel-perfect constraints. The implementation must retain the hierarchy, seriousness, contrast, content clarity and restrained motion described in docs/ART_DIRECTION.md and docs/MOTION_DIRECTION.md.
